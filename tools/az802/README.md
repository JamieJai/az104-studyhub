# AZ-802 CBT

`D:\Users\USER\Downloads\az104-studyhub` 의 AZ-104 CBT 폼을 따라 만든 AZ-802 연습 시스템 (독립 정적 사이트, 로그인 없음).

- 현행 AZ-802 문항 63개 (#1~63)
- 구형 AZ-800/AZ-801 문항 중 AZ-802 현행 범위에 해당하는 377개 (#101~477) — 전 문항 한국어 번역 완료

## 실행

`index.html` 을 브라우저에서 바로 열면 됩니다. (또는 폴더에서 `python -m http.server 8802` → http://localhost:8802)

진행 기록·북마크·모의고사 기록은 브라우저 localStorage 에 저장됩니다. 다른 기기로 옮기려면 사이드바 "기록 내보내기/가져오기" 를 쓰세요.

## 문항 카드 순서

1. (구형 문항이면) 상단 안내 배너 — `구형 AZ-801 문제 · 원본 Q309 · AZ-802 분류: 영역 › 세부 스킬`
2. 원본 이미지 (표·그림, 클릭하면 확대)
3. 한국어 번역 텍스트 — 아래 "EN · 영어 원문 보기" 를 펼치면 실제 시험 표현 확인
4. 답 입력 (객관식 / HOTSPOT 드롭다운 / DRAG DROP / 예·아니요 / 자기 채점)
5. 정답 및 해설 (한국어 해설 + 영어 원문 해설 + Learn more 링크)

## 구형 AZ-800/801 문항

- 출처: `..\az-800-801-merged\az802_legacy_bank.json` (AZ-800 277 + AZ-801 325 문항 중 AZ-802 2026-06-22 학습 가이드 범위에 맞는 377개만 남김, 225개 제외 — 분류 근거는 그 폴더의 README/classification.csv)
- 7개 AZ-802 출제 영역에 그대로 섞여 들어가며, 사이드바 필터 "구형 AZ-800/801 문제만 / 현행 문제만" 으로 분리해 볼 수 있습니다.
- **모의고사 설정 → "구형 AZ-800/801 문제 포함"** 체크박스로 모의고사 풀에 넣거나 뺄 수 있습니다 (기본: 미포함). 포함 시 영역별 가중치는 그대로이고 풀만 커집니다.
- 문항 번호 이동 칸에 `101`~`477` 또는 `801-309` 처럼 `시험-원본번호` 로 입력해도 이동합니다.
- "자기 채점" 유형 4문항 (정답이 이미지로만 제공되는 HOTSPOT) 은 정답 공개 후 맞음/틀림을 직접 표시하며, 자동 채점이 불가능해 모의고사에서는 제외됩니다.
